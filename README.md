# Charter Bench

A study site for the Grade 12 Canadian & International Law Unit 2 test
(Rights and Freedoms): the Charter, s. 1 and the Oakes test, s. 33,
s. 25 / s. 35 Indigenous rights, human rights codes, the UDHR, the case
studies and the films on the review sheet.

Live site: https://ronfinis.github.io/charter-bench/

## Files

| File | What it is |
| --- | --- |
| `charter-bench.html` | **Source of truth.** All content, styles and code. Edit this one. |
| `build.py` | Wraps the source into a full web page. |
| `index.html` | Generated by `build.py`. This is what GitHub Pages serves. Don't edit by hand. |

## Updating the site

```
python build.py
git add -A
git commit -m "Describe the change"
git push
```

GitHub Pages republishes within a minute or two of the push.

Progress (XP, streak, flashcard boxes, checklists) is saved in each
browser's local storage, so it stays on the device you study on.
